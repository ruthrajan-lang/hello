How to read this

Judging a release

Write the claim as a chain

Engagement, then outcome, then guardrail. For example: a faster pause, then fewer support contacts about parental controls, with no rise in people turning alerts off.

Agree the bar first

Each success bar is set before the release ships and drawn as a dashed line, so the result can't be argued into a win afterwards.

Roll out in waves

Households are assigned to two waves at random within platform and plan. Wave 2 gets each release 7 weeks later, so it shows what would have happened anyway. The lines should run together before the marker.

Judge weeks 3–6

The first weeks are novelty and learning. "Vs own baseline" compares each wave with its own 4 weeks before release and shades weeks 3–6.

Split before you celebrate

An average can hide a group that got worse. Check platform, households with children, and plan before calling a release done.

Compare rates, not totals

Rates per household or per session stay comparable as the number of Shield households grows.

Add your own marker

Mark something that might move the numbers, like an outage or a marketing push. It's saved in this browser only.
